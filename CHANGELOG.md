# Changelog

## v1.0.0 — May 2026

### Added
- MilkSupplyChain smart contract deployed on Celo Mainnet
- `/tracker` page with live blockchain batch lookup
- `/tracker/[id]` shareable SSR batch detail pages
- `/tracker/stats` on-chain stage distribution statistics
- `/api/chain` REST API for batch data
- `/api/chain/recent` latest N batches endpoint
- `/api/chain/stats` stage distribution endpoint
- `/api/health` uptime monitoring endpoint
- `/about`, `/blog`, `/contact`, `/privacy`, `/terms` pages
- Full component library: Badge, Button, Card, Input, Alert, Modal, Skeleton, Tooltip, CopyButton, ProgressBar, StatCard
- Custom hooks: useBatch, useBatchCount, useRecentBatches, useSearchHistory, useLocalStorage, useDebounce, useToggle
- Persistent search history via localStorage
- Share button for individual batch URLs
- FAQ, Stats, Partners, Newsletter sections on landing page
- GitHub Actions CI workflow
